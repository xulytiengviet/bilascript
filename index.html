BẢN CHẤT

Bila làm chủ cách viết

Lexer, semantic token identity, parser, AST, semantic diagnostics, normalization và code-generation policy thuộc frontend BilaScript. neub được chuyển thành KW_IF; AST chỉ còn IfStatement.

JavaScript làm nhiệm vụ chạy

Output là JavaScript trực tiếp. V8, SpiderMonkey, JavaScriptCore, Node và Bun tiếp tục đảm nhiệm JIT/runtime. BilaScript không cố viết lại một JavaScript VM.

Giữ nguyên JavaScript symbols

{ } ( ) [ ] + - * / === !== => ?. ?? ... và numeric literals không bị dịch sang từ tự nhiên.

Receiver-safe alias

ds.dayq() chỉ thành ds.push() khi compiler suy luận ds là Array. Unknown API được giữ nguyên thay vì rewrite mù.

Source span + map

Token/AST giữ vị trí nguồn; CLI có --map để phát source map v3 mà không thêm runtime overhead.

LỊCH SỬ NÂNG CẤP

v1.0.0 — CVNSS4.0 trên Babylscript/Rhino

Khởi đầu bằng việc đưa vocabulary CVNSS4.0 vào cơ chế JavaScript đa ngôn ngữ của Babylscript, chứng minh khả năng thay đổi bề mặt ngôn ngữ.

v1.2.0 — Native Bila language mode

bila trở thành language mode thật trong tokenizer; bổ sung API mapping và chính sách collision parser-safe.

v2.0.0 — JavaScript-compatible grammar

Chuẩn hóa ---bila---, ---bila:strict---, ---bila:js---; giữ punctuation/operators JavaScript và xây spec/lexical bridge.

v3.0.0 — Native CVNSS4.0 frontend

Tách khỏi Rhino làm frontend chính: Bila Lexer → Bila Parser → Bila AST → Semantic → JavaScript Codegen.

v3.5.0 — Zero-cost frontend

Semantic KW_* IDs, source span/map, receiver-safe aliasing, Unicode identifiers, modern structural operators, zero-runtime-helper contract và website Pascal-inspired.

Đánh giá toàn diện

ƯU / NHƯỢC / RỦI RO

ƯU ĐIỂM

  • Frontend ownership rõ ràng hơn v3.0.
  • Không runtime translation cho mapping 1:1.
  • Giảm nguy cơ phá API nhờ receiver-safe mapping.
  • Giữ tương thích tư duy JavaScript qua symbols/operators.
  • Source map và semantic IDs là nền cho LSP/type tooling.

GIỚI HẠN

  • Chưa full ECMAScript/Test262.
  • Type inference còn nhẹ.
  • Template `${...}` chưa hỗ trợ.
  • Class/module/async-await đầy đủ chưa có.
  • Chưa có benchmark để công bố delta hiệu năng định lượng.
