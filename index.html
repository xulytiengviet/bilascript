LOOP 1

COMPILE-TIME SAFETY

Strict alias proof

ds.dayq() chỉ hạ thành ds.push() khi receiver được chứng minh là Array. Không đủ bằng chứng trong bila:strict → BILA-T310 và dừng compile.

Type annotation zero-cost

bilb ds: Magz<Sob> tồn tại để cung cấp bằng chứng frontend; annotation bị xóa khỏi JavaScript output, không sinh runtime checker.

LOOP 2

TOOLING + LANGUAGE SERVICE

V4 có diagnostics, completion, hover, document symbols, LSP stdio tối thiểu và TypeScript oracle tùy chọn. TypeScript chạy offline để bổ sung hiểu biết ecosystem; Bila vẫn là nguồn chân lý cho CVNSS4.0 và alias lowering.

CONFORMANCE HARDENING

Positive/negative corpus, 100-case deterministic operator differential test, zero-helper audit, source-map smoke test và tooling tests. V4 không tự nhận full Test262 hay nhanh hơn JavaScript.

ƯU / NHƯỢC

Ưu điểm

Dời alias risk về compile-time; output JS sạch; npm/user API không rewrite mù; frontend ownership rõ; tooling và testability tốt hơn.

Giới hạn

Chưa full ECMAScript/Test262; flow typing còn vừa phải; một số modern keyword chưa có canonical CVNSS4.0; TypeScript chỉ là oracle tùy chọn.
