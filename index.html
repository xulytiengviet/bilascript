Bản chất của BilaScript v3

V3 không cố tạo một JavaScript VM mới. Nó tạo một compiler frontend riêng nhưng duy trì cấu trúc lập trình quen thuộc của JavaScript. Mã nguồn CVNSS4.0 được biến thành token Bila, AST Bila, được kiểm tra ngữ nghĩa rồi mới hạ xuống JavaScript.

Điểm thay đổi cốt lõi là ranh giới sở hữu: JavaScript không còn quyết định vocabulary hay parser của core v3; nó là một target code-generation. Điều này cho phép Bila tiến hóa grammar/tooling mà vẫn tận dụng hệ sinh thái JavaScript.

Vấn đề nghiên cứu

V1–v2 chứng minh JavaScript có thể mang vocabulary CVNSS4.0 nhưng vẫn gắn mạnh với Rhino/Babylscript. V3 đặt câu hỏi khác: có thể kiểm soát frontend mà vẫn giữ JavaScript làm backend hay không?

Phương pháp

Chúng tôi triển khai lexical analyzer, recursive-descent/precedence parser, AST, semantic pass và JavaScript code generator độc lập trong v3. Unit test kiểm tra strict mode, English compatibility, AST structure, diagnostics và thực thi output.

Kết quả

Kết quả ở v3.0 là kiến trúc, không phải tuyên bố benchmark: compiler stages đã tách khỏi Rhino và output có thể chạy bằng JavaScript runtime. Không công bố số liệu tốc độ hay “% tương thích ECMAScript” khi chưa có conformance corpus đầy đủ.

Ưu điểm

  • Làm chủ lexer/parser/AST/diagnostics.
  • Cú pháp quen thuộc với JavaScript.
  • Backend JS có hệ sinh thái lớn.
  • Cấu trúc dễ test, audit và mở rộng.
  • Core mới có MIT provenance rõ.

Nhược điểm / giới hạn

  • V3.0 mới là core subset, chưa full ESNext.
  • Chưa có source map/LSP/debugger đầy đủ.
  • Runtime semantics cuối cùng vẫn phụ thuộc JS backend.
  • Chưa có type system tĩnh hay optimizer IR.
  • Cần tiếp tục audit collision CVNSS4.0.

Đe dọa tới tính hợp lệ

Test hiện chủ yếu unit/smoke tests; chưa tương đương Test262. Khả năng học dễ hơn chưa được xác nhận bằng nghiên cứu người dùng. Vì vậy trang này cố tình không biến đánh giá định tính thành số liệu định lượng giả.

Công dụng

Giáo dục lập trình bằng CVNSS4.0; nghiên cứu localized programming languages; transpilation; sandbox/browser experimentation; công cụ học song song Bila↔JavaScript; tiền đề cho LSP, formatter, optional types và backend WebAssembly.

Roadmap
